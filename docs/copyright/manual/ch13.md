| 任务优先级 | 最低、低、中、高、紧急 | 五档 |

| 通知访问范围 | 本人、组织管理员、组织全员 | 决定通知接收人 |
| 附件来源 | 上传、外链 | 两种附件形态 |
| 附件存储方式 | 本地磁盘、对象存储 | 可配置切换 |
| 附件可见性 | 公开、受限 | 受限附件需凭证访问 |
| 审计动作 | 创建、更新、删除 | 由请求方法推断 |

| 触发方式 | 定时、手动、回调 | 检查触发来源 |
| 执行状态 | 成功、失败、超时、跳过 | 失败与超时区分记录 |
| 探针范围 | 系统探针、租户探针 | 归属范围 |

| 订单状态 | 待支付、已支付、已取消、已退款 | 单向流转 |

| 工单作者类型 | 用户、平台 | 区分对话方 |

| 201 | 资源创建成功 | 记录返回的资源标识 |
| 204 | 成功但无返回内容 | 不做数据解析 |
| 400 | 参数校验失败 | 按字段级错误提示修正请求 |
| 401 | 未认证或令牌失效 | 使用刷新令牌换取新令牌，失败则重新登录 |
| 403 | 权限不足 | 检查角色等级与项目授权，不要重试 |
| 404 | 资源不存在或已删除 | 确认标识正确，必要时刷新列表 |
| 409 | 状态冲突 | 读取最新状态后再操作，避免并发覆盖 |
| 429 | 触发频率限制 | 按提示时间退避后重试，避免密集重试 |
| 500 | 服务内部错误 | 记录请求标识并联系运维，不要盲目重试 |
| 503 | 服务暂不可用 | 服务处于维护或未就绪，退避重试 |
