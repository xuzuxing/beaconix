## 3. 系统总体设计

### 3.1 设计目标与原则
多租户强隔离、权限最小化、接口无状态化、异步任务与告警不阻塞主链路、数据可追溯、可水平扩展。

### 3.2 总体架构
分层描述：接入层（反向代理/HTTPS）→ 应用层（NestJS 模块化单体）→ 领域层（29 个业务模块）→ 基础设施层（数据库、Redis 队列、日志、观测、对象存储）→ 外部集成（邮件、微信、IM 渠道）。配「系统架构图」。

### 3.3 请求处理流程
全局中间件与管线顺序：Helmet → CORS → ValidationPipe（DTO 白名单校验/类型转换）→ 限流（Throttler）→ JWT 鉴权（全局 APP_GUARD，`@Public()` 放行）→ 租户/项目鉴权 → 控制器 → 业务服务（Prisma）→ 响应包装 `{ data, meta }` → 全局异常过滤器。配「请求处理流程图」。

### 3.4 模块划分与职责
表格：模块名 / 职责 / 主要数据实体 / 所属域。覆盖第 4–9 章全部模块。

### 3.5 数据模型设计
- 数据实体总览：40+ 模型分域列举（账号与安全、组织与成员、协作、监控、告警与渠道、探针、计费、工单、平台设置）。
- 核心实体关系：User–Membership–Organization–Project–Sprint–Task–Comment/Attachment/Label；Monitor–MonitorState–ProbeResult–AlertEvent–NotificationChannel。
- 关键设计说明：软删除（`deletedAt`）、审计快照、时间序列分表（检查日志/监控历史）、枚举字典集中管理。配「核心 ER 图」。

### 3.6 接口规范
统一前缀 `/api`；认证头 `Authorization: Bearer <JWT>` 与 `bk_org_...` API Key 双通道；统一响应体与分页结构；HTTP 状态码与业务错误码约定；时间格式与字段命名；接口文档 `/api/docs`（Scalar 界面）。

## 4. 账号与身份认证

### 4.1 用户注册与邮箱验证
邮箱+密码注册，写入用户与其默认资料；系统下发 6 位 OTP 验证码（含有效期与重发节流），验证通过后在同一事务内完成邮箱确认并**自动开通默认组织与首个项目**（幂等，已有组织则跳过）。

### 4.2 用户登录与令牌管理
账号密码登录（bcrypt 校验），签发 access token + refresh token；refresh 采用**轮换机制**（旧令牌作废、新令牌签发），登出时吊销刷新令牌；令牌表记录设备与过期时间以支持清理。

### 4.3 密码找回与修改
忘记密码走 OTP 校验后重置；已登录用户可修改密码，改密后触发站内通知并吊销历史刷新令牌。

### 4.4 双因素认证（TOTP）
生成密钥与二维码 → 用户绑定验证器 → 启用；登录时若已启用则先行返回二次验证挑战，用户提交动态码或**一次性恢复码**完成登录；支持重新生成恢复码、关闭 2FA（需校验），并对启用/关闭/使用恢复码等事件记录通知。

### 4.5 第三方登录（微信生态）
网页授权登录、小程序登录（code 换会话）、小程序二维码扫码登录与二维码状态轮询；微信身份与本地账户通过 `UserIdentity` 绑定，支持多身份共存。

### 4.6 个人信息管理
查询与修改个人资料、修改密码；个人访问令牌（PAT）在 9.1 中单列。

### 4.7 会话与安全策略（本节可与 10.1 合并）
登录失败计数与限流、令牌有效期与刷新窗口、维护模式下的写操作拦截。

## 5. 组织、成员与权限

### 5.1 组织（租户）管理
组织的创建、列表、详情、更新（名称/描述/设置）、软删除与所有权转移；组织是所有业务数据与计费的最小隔离单元。

### 5.2 成员管理
成员列表（含角色、状态、加入时间）、调整成员角色（OWNER/ADMIN/MEMBER/VIEWER 四级，OWNER 唯一）、成员主动退出、管理员移除成员；相关变更全部落审计并推送通知。

### 5.3 角色与权限模型
- 组织级：四级角色按**最小权限**语义匹配（`@Roles` 指定最低等级）。
- 项目级：项目成员与项目授权（project membership / grants），支持"我的权限"查询与按成员配置项目级权限；监控等资源配置访问锁（access locks）细化到监控/规则/状态页。
- 全局超管角色可跨租户运维（仅限管理后台接口）。

### 5.4 邀请机制
管理员以邮箱发起邀请（可选角色与项目授权），生成一次性令牌与有效期；被邀请人可在登录后于"待处理邀请"中查看并接受/拒绝；支持撤销、过期自动失效（定时任务）与邀请事件通知。

### 5.5 组织设置与公共配置
组织级配置读写；对外暴露白名单化的公开设置（如注册开关、品牌信息）。

## 6. 敏捷项目协作

### 6.1 项目管理
项目 CRUD、归档（只读）与恢复、项目标识键（key）用于生成任务编号；项目支持成员维护与默认配置。

### 6.2 迭代（Sprint）管理
迭代创建、排序、状态流转（Planned → Active → Completed）、启动与完成（含未完成任务的处理规则）、列表与详情；状态变更触发成员通知。

### 6.3 任务管理
任务全生命周期：创建（标题、描述、优先级、状态、故事点、指派人、迭代、截止时间、父任务）、更新、删除与恢复、指派/转派、在迭代与**待办池（Backlog）** 之间移动、按多条件筛选与分页；支持子任务层级。

### 6.4 任务依赖与关注
任务间依赖关系的建立与解除（阻塞/被阻塞，解除阻塞触发通知）；用户可关注/取消关注任务，关注者在任务变更时接收通知。

### 6.5 任务活动日志
任务字段变更自动记录活动（变更人、字段、旧值→新值、时间），形成任务时间线，供详情页展示。

### 6.6 评论
任务下的多级（嵌套）评论，支持回复、编辑与软删除；@提及与回复触发通知。

### 6.7 附件
两类入口：任务内上传（`multipart`）与外部链接式附件登记；支持下载（签名或直链）、删除；存储抽象为本地磁盘/S3 兼容 OSS，附件含可见性（公开/受限）与来源标识。

### 6.8 标签
组织级与项目级标签的创建、修改、删除；标签与任务多对多绑定与解除，用于筛选与看板着色。

### 6.9 通知中心
- 站内通知：列表、详情、单条/全部已读、未读数、删除；
- 实时推送：基于 SSE 的长连接通道，断线自动重连；
- 通知类型覆盖任务、迭代、成员、邀请、权限变更、密码与 2FA、支付与订阅、监控告警、API Key/PAT、探针、工单等 50+ 事件；
- 可靠投递：邮件等外部通道经投递记录（NotificationDelivery）与重试机制保证最终送达。

### 6.10 审计日志
以装饰器声明式采集：按 HTTP 方法推断动作（增/改/删），变更前拉取实体快照、变更后取响应快照，对密码/令牌类字段自动去敏，异步写入**不可变**审计表；支持按组织、时间、实体、操作者查询。审计失败不影响业务响应。

## 7. 可用性监控平台

### 7.1 监控项管理
创建/编辑/查询/软删除监控（名称、目标地址、类型、检查频率、超时、断言、所属项目、绑定探针），暂停与恢复、删除后恢复；可对监控做**告警通道测试**。

### 7.2 多协议检查能力
支持 11 类检查：HTTP(S)（含状态码/响应体/响应头/耗时断言）、TCP、PING、DNS、MySQL、PostgreSQL、Redis、MongoDB、Docker、gRPC、WebSocket；数据库与容器类检查通过隔离运行时执行，避免阻塞主进程。

### 7.3 检查执行与调度
调度器按监控频率将检查任务投放队列（BullMQ），由工作进程并发执行；支持**手动触发检查**、按监控查询检查记录；执行结果记录触发方式（定时/手动/回调）、耗时、错误原因与执行状态（成功/失败/超时/跳过）。

### 7.4 状态判定与历史
按规则将检查结果聚合为监控状态（UP / DEGRADED / DOWN / PAUSED / UNKNOWN），维护当前状态快照与状态变更历史；保留检查日志、监控历史与可用率时间序列，配套数据保留与清理策略。

### 7.5 监控看板与洞察
组织级与项目级概览（监控数、状态分布、异常列表）、可用率统计、状态码分布、单监控洞察（响应时间趋势、最近事件、探针维度对比）。

### 7.6 告警规则与绑定
规则组（组织级）的新增、查询、修改、删除；规则元数据（可选指标、比较符、阈值模板）下发；规则组与监控的**绑定/解绑**决定该监控的告警判定策略；支持可用率类告警与连续失败次数类告警。

### 7.7 告警事件与投递
状态越限生成告警事件（触发/恢复），记录触发规则、严重级别与时间；按监控绑定的通知渠道生成投递记录，失败可**手动重试**；告警与恢复同时推送站内通知。

### 7.8 通知渠道
支持飞书、企业微信、钉钉、微信订阅消息、邮件五类渠道的创建、查询、修改、删除；提供渠道连通性**测试发送**与投递日志查询；渠道配置中的密钥类字段加密与脱敏展示。

### 7.9 分布式探针
- 探针生命周期：创建、查询、修改、删除、密钥轮换、连通性校验；
- 注册与激活：设备码注册、令牌注册、激活页确认、管理员审批、凭据兑换、凭据吊销；
- 运行上报：心跳（在线/离线判定）、检查结果批量上报、执行记录查询、结果查询；
- 监控绑定：为监控分配一个或多个探针，实现多地域探测与结果对比；
- 系统探针：平台级探针池与租户隔离，支持**负载再平衡**。
- 配套：探针代理 CLI（登录、运行、校验、状态、停止、打包发布）。

### 7.10 公开状态页
创建状态页（名称、slug、简介、展示的监控列表、品牌信息），配置后通过公开地址 `/status/:slug` 免鉴权访问，展示所选监控的当前状态与近期事件；支持修改与删除。

## 8. 运营、计费与工单

### 8.1 套餐与配额
套餐（Plan）与计费周期（PlanTerm）管理；组织订阅（Subscription）状态机：ACTIVE / PAUSED（被更高等级订阅压制，剩余天数冻结）/ EXPIRED / CANCELLED；配额查询（监控数、探针数、成员数等按套餐限制）。

### 8.2 订单与支付
下单（选择套餐/周期）、取消订单、支付发起；对接微信支付（含 V3 回调验签，基于原始报文字节），回调驱动订单状态与订阅生效；支持管理员侧标记支付、退款与取消。

### 8.3 订阅到期与续期
定时任务扫描临期/到期订阅，发送续费提醒并执行到期降级；相关事件推送站内通知。

### 8.4 工单系统
用户侧：提交工单（分类、标题、内容、附件）、提交回复、关闭工单、查看工单与活动记录、工单分类查询；管理侧：工单列表与统计、详情、状态与指派人变更、回复、删除；双方操作均留痕（TicketActivity）并互相通知。

### 8.5 管理后台
- 租户管理：租户列表、详情、启用/停用；
- 订单管理：列表、详情、标记已支付、退款、取消；
- 套餐管理：套餐增删改查；
- 审计日志：全局审计检索；
- 运营指标：调度队列指标、平台概览、租户维度指标；
- 系统探针管理：创建、校验、启停、再平衡、删除；
- 工单与工单分类管理；
- 系统设置管理。
所有后台接口要求全局超管身份，并单独记录审计。

### 8.6 系统设置
键值化设置项（字符串/数字/布尔/JSON 等类型），支持按分组读取与更新、公开项对外输出；支持"开发调试模式"等运行期开关。

## 9. 开放能力与集成

### 9.1 开发者凭据
组织级 API Key（前缀 `bk_org_`，可创建/列出/吊销，仅创建时明文返回）与个人访问令牌 PAT（按用户创建/列出/吊销），凭据操作触发通知与审计。

### 9.2 开发者 API（`/developer/v1`）
面向外部集成的精简接口面：组织概览、监控的查询/创建/更新/暂停/恢复/删除/恢复、探针相关操作、状态页增删改查；鉴权走 API Key 或 PAT，权限沿用组织成员关系。

### 9.3 第三方集成
邮件（验证码、邀请、重置密码、任务提醒等模板化邮件）、企业 IM（飞书/企微/钉钉机器人）、微信订阅消息、微信登录与微信支付、S3 兼容对象存储。

### 9.4 接口文档与联调
Swagger/OpenAPI 自动生成 + Scalar 交互界面（`/api/docs`），支持 Bearer 与 API Key 两种鉴权方式在线调试。

## 10. 安全设计

### 10.1 认证与凭据安全
bcrypt 口令哈希存储；JWT 有效期与刷新轮换；OTP 一次性、限次、限时；2FA 恢复码单次使用；API Key/PAT 只存哈希前缀+密文；敏感字段响应脱敏。

### 10.2 授权与越权防护
全局默认鉴权（未标记 `@Public()` 一律需要令牌）；组织成员校验与角色等级校验；项目级访问控制与资源锁；租户 ID 由路径参数/父资源解析后二次校验，杜绝跨租户访问；超管通道独立守卫。

### 10.3 多租户数据隔离
所有业务表带组织外键，服务层查询强制携带组织/项目条件；唯一约束按组织维度建立（如项目 key、状态页 slug）；跨租户引用在服务层校验。

### 10.4 传输与存储安全
Helmet 安全响应头与 CSP、CORS 白名单、HTTPS 部署要求、上传文件类型/大小限制与存储目录隔离、回调验签。

### 10.5 审计与合规
不可变审计日志、操作人/来源 IP/UA 记录、敏感字段去敏、审计独立查询权限（仅管理端与组织管理员）。

### 10.6 限流与防护
全局与接口级限流阈值、登录/验证码/找回密码等敏感接口加强限流、维护模式开关、异常统一处理避免信息泄露。
