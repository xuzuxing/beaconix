# 支付与退款对接补充（迭代 B）

更新：2026-10-29。所有业务 API 使用 `/api` 前缀和 JWT，响应仍为 `{ data, meta }`；渠道回调保留原生应答格式。

## 发起支付

`POST /api/orders/:id/pay` 请求字段不变。微信 V3 必须传 `openid`，支付宝可选择 `payMethod`，小程序虚拟支付必须传新的 `wx.login()` `code`。

三个渠道的返回值均含 `data.outTradeNo`：它是本次支付尝试的商户单号。微信 V3 和支付宝为 `P` 加 30 位随机十六进制字符；虚拟支付沿用 `V` 前缀。其余 JSAPI、收银台/二维码、虚拟支付签名字段保持原契约。

```json
{
  "data": {
    "outTradeNo": "P0123456789abcdef0123456789abcd",
    "timeStamp": "1793260800",
    "nonceStr": "...",
    "package": "prepay_id=...",
    "signType": "RSA",
    "paySign": "..."
  },
  "meta": { "timestamp": "2026-10-29T08:00:00.000Z" }
}
```

- 同一订单每次重试支付都会生成新单号。客户端按订单 `id` 查询订单，不能将 `outTradeNo` 当作订单 ID，也不要复用上一次调用得到的支付参数。
- 微信/支付宝的支付有效期来自订单 `expiresAt`。订单已取消、已退款、已付或到期时不能重新发起支付。
- SDK 或收银台返回成功后，轮询已有的 `GET /api/orders/:id`，以 `data.status === "PAID"` 作为开通成功依据。
- 回调遗漏时，后台每五分钟扫描未终态尝试并向渠道查单；批次上限 100 条，因此五分钟是调度周期，积压或渠道异常时不保证五分钟内完成。页面短轮询结束后可提示“正在确认支付结果，稍后可在订单中查看”，保留刷新入口。
- 不同尝试或渠道重复付款只开通一次；第二笔会记录资金事实，并向下单人和组织管理员发站内/邮件通知，交由人工核查退款。

## 取消订单

用户与管理员取消、订单到期取消共用流程：先查渠道是否已付款，再尝试关单。如果查到成功付款，订单完成结算，取消请求返回订单已非待支付的错误；前端刷新订单状态即可。

关单失败会记录 `closePending` 与 `lastError`，本地订单仍可进入 `CANCELLED`，后台继续重试。已签发的支付凭据在渠道确认关闭前可能仍可付款，前端收到取消成功后应停止使用此前的支付参数。晚到的成功付款不会重新激活已取消/已退款订单，会记录付款并通知人工退款。

支付宝未打开的 PAGE/WAP 收银台链接可能尚未创建渠道交易。查询 `ACQ.TRADE_NOT_EXIST` 视为待支付；关单同样返回该码时继续保留重试，不能宣称链接已失效。

## 退款与回调

用户退款仍使用 `POST /api/orders/:id/refunds` 与既有退款查询接口，金额由服务端计算。退款发起和退款查询使用实际结算的支付尝试单号；历史微信/支付宝支付回退到原订单号，历史虚拟支付通过渠道交易号定位原尝试。

微信退款回调核对退款金额、原订单金额和本地退款渠道；报文包含币种、商户单号或渠道交易号时也必须与原支付一致。缺金额、金额不符或身份不符时返回 `400 + { code: "FAIL" }`，不推进退款、订单或订阅。

回调地址不变：

| 渠道 | 地址 | 应答 |
| --- | --- | --- |
| 微信支付 | `POST /api/payment/wechat/callback` | 裸 `{ code: "SUCCESS" }` / `400 + FAIL` |
| 支付宝 | `POST /api/payment/alipay/callback` | 纯文本 `success` / `failure` |
| 微信退款 | `POST /api/payment/wechat/refund-callback` | 裸 `{ code: "SUCCESS" }` / `400 + FAIL` |
| 虚拟支付 | 既有 `/api/payment/wechat-virtual/notify` | 既有 JSON/XML 协议 |

## 验证范围

单测和离线 HTTP 集成覆盖下单→回调/查单→订阅→退款→对账，使用内存事务夹具与模拟渠道，不连接真实数据库。已准备迁移与旧单回填；真实 PostgreSQL 迁移、并发锁及真实渠道联调按本轮范围未执行。
