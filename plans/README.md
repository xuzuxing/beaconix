## 未采纳的原方案假设

- 新增协议只需要 Checker 和注册：当前独立 Agent、结果身份与套餐体系也必须协作。
- SSL、关键词、JSON 必须分别成为 MonitorType：优先作为 HTTP 能力，独立 TLS 目标按需求另评估。
- `config: any` 可直接保存：缺少运行时校验、兼容规则与敏感数据边界。
- 所有类型一次写入枚举或默认开放：可能让未实现或无执行器的类型进入调度。
- 首期 2-3 天是完整交付承诺：原估算未覆盖双执行链路、安全、迁移和回归。
