## 已考虑但未采用

- 组织 MEMBER 限制最高为项目 MEMBER：无法表达局部项目管理员，不采用。
- 给所有现有组织成员自动回填全部项目：保留现有泄漏语义，不采用。
- 用组织 ADMIN 邀请实现受限项目管理：组织角色会扩张到全部项目，不采用。
- 仅 expectedVersion 防并发覆盖：重新加入会产生新成员代次，改为 ID 与版本联合校验。
- 仅查询当前 SUPER_ADMIN 防旧邀请复活：失权再恢复仍可能满足当前身份条件，改为数据库维护的平台身份代次联合校验。
- 仅 Guard 或 frontend 隐藏：无法保护聚合、历史通知、缓存和公开存储，不采用。
- 投递前复查等于严格即时撤权：外部副作用不能被数据库原子提交，改为明确在途边界；用户已批准本版规则，相关代码已接入，真实数据库及发布验收仍待完成。
- 直接沿用不存在的通知 PostgreSQL harness 或静默跳过数据库测试：改为独立白名单、自动迁移和零跳过验收。
